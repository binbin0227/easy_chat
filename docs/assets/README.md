# Easy Chat project icon

`easy-chat-logo-v1.png` was generated with OpenAI's built-in image generation
tool on 2026-10-08, following the maintainer's choice of a pixel-art design.
It is an illustrative project icon, not an in-game screenshot.
Any rights held by Easy Chat contributors in this asset are offered under the
root MIT license. It is not an official Minecraft, Mojang, Microsoft or Lunar icon.

Design prompt: original square pixel-art icon; two teal and golden-yellow
speech bubbles bearing "中" and "A", connected by exchange arrows; high contrast
on navy, readable at small sizes; no game artwork, brand marks or watermark.
